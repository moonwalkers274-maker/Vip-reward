# Deepanshu Invite Rewards

This Android project is a reward-app interface prototype. It records redemption requests locally; it does not transfer money. Connect a legitimate payment provider and backend before offering real withdrawals.

## Build on GitHub
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Open **Actions** → **Build Invite Rewards APK** → **Run workflow**.
4. When the workflow finishes, open the run and download the `DeepanshuInviteRewards-debug` artifact.
5. Extract the ZIP to get `app-debug.apk`.
